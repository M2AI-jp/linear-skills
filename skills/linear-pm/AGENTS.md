# PM系統の責任

このリポジトリ自体を開発する場合だけ、既存の開発入口から正本・担当Issue・技術方針を確認する。配布先では利用者の既存入口・指定Project・正本を引き継ぎ、開発Projectや開発専用SSOT.mdを要求しない。共通規則は[共通運用契約](../linear/references/contract.md)。`SKILL.md`は現在計画から実行・評価・訂正・引継ぎを進め、`agents/openai.yaml`は明示起動だけを担う。

計画の不足は[Refresh](../linear-refresh/SKILL.md)へ返す。操作・再開・終了の変更はHookとGit・業務評価へ接続する。構文はskill-creatorのquick_validate.py、実行と接続の評価は担当Issueの受入で確認する。
